# FlashOutBox

FlashOutBox is a simple app (built using Python Fastapi and Flutter) to remote control core functions of ETC Eos lighting consoles, specificially the ability to fire cues and read cue notes remotely.

This is basically a proof of concept for me, to prepare for larger projects of this architecture. I want to learn more about flutter, so building something a bit smaller and simpler frontend wise is a priority for me.
